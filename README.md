# selfish-mini-admin

워크숍에서 만든 내 사이트에 **비밀번호 하나짜리 관리자 페이지(/admin)** 를 붙여 주는 Claude Code 스킬입니다.
"내가 아닌 사람이, 나 없이, 자주 바꿔야 하는 것"을 AI가 코드에서 찾아 제안하고, 고른 것만 어드민으로 뺍니다. DB가 없으면 Supabase 를 붙여 줍니다.

## 언제 쓰나
- 사이트는 만들었는데, 글자 하나 바꾸려고 매번 클로드를 켜고 배포하는 게 번거로울 때
- 팀원·가족이 내용을 바꿔야 하는데 코드를 모를 때
- 문의 폼은 있는데 들어온 걸 볼 데가 없을 때

먼저 인정하고 시작합니다. 나 혼자 쓰고, 가끔 바꾸면 어드민은 낭비예요. 그런 경우 스킬이 "지금은 필요 없다"고 말하고 끝냅니다.

## 설치
```bash
git clone https://github.com/selfishclub/selfish-mini-admin ~/.claude/skills/selfish-mini-admin
```
프로젝트 폴더를 연 채로 "어드민 만들어 줘"라고 하면 됩니다.

## 준비물 (전부 무료)
GitHub 에 올라간 사이트, Vercel 배포, Supabase 계정(브라우저에 로그인만 돼 있으면 프로젝트 생성·연동은 AI가 합니다).

## 무슨 일이 일어나나
1. AI가 저장소를 읽고 표로 보여 줍니다 — 무엇으로 만들었나, DB가 있나, 폼이 있나, 코드에 박힌 글자가 뭔가.
2. "이건 어드민으로 빼고, 이건 코드에 두자"를 제안합니다. 고르면 시작.
3. DB가 없으면 Supabase 를 만들고 Vercel 에 연결합니다. 키는 사람이 옮기지 않습니다.
4. 코드에 박힌 글자를 DB로 옮기고, 사이트가 DB를 읽게 고칩니다. 디자인은 안 건드립니다.
5. /admin 을 만듭니다. 비밀번호는 여러분이 Vercel 에 직접 넣습니다.
6. 어드민에서 글자 하나 바꾸고 사이트에서 확인합니다. 그게 오늘의 "됐다"입니다.

## 예시 대화
- "어드민 만들어 줘. 문의 들어온 거 보고 싶고, 소개 문구는 폰으로 고치고 싶어."
- "설계도 v3 있어. 이대로 어드민 붙여 줘."
- "우리 사이트에 어드민이 필요한지 모르겠어. 봐 줘." → 필요 없으면 없다고 답합니다.

## 하지 않는 것
키·비밀번호 입력, 결제·플랜·계정 생성, 삭제, 디자인 변경. UTM·GA·대시보드가 필요하면 [sponge-admin-kit](https://github.com/selfishclub/sponge-admin-kit).
