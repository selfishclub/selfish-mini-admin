# 10 · 판단 — 무엇을 어드민으로 뺄까

## 한 줄 기준
**내가 아닌 사람이, 나 없이, 자주 바꿔야 하는가?** 하나라도 예면 어드민. 셋 다 아니오면 만들지 않는다.
먼저 인정하고 시작한다: 나 혼자 쓰고, 가끔 바꾸고, 코드 고치는 게 안 무서우면 어드민은 낭비다. 클로드에게 말하는 게 더 빠르다.

## 후보를 뽑는 규칙 (00-detect 7번·6번을 재료로)
| 종류 | 코드에서 이렇게 보인다 | 어드민에서는 | 표 |
|---|---|---|---|
| 접수함 | 문의·신청·예약 폼이 있는데 저장이 안 되거나 메일만 감 | 들어온 것 목록 + 확인/완료 상태 | inquiries |
| 짧은 글 | 제목·한 줄 소개·가격·공지 문자열 | 한 줄 입력 칸 | site_content (type: text) |
| 긴 글 | 소개문·안내문 여러 문단 | 여러 줄 입력 칸 | site_content (type: longtext) |
| 목록 | 링크·FAQ·메뉴·프로젝트·메뉴판 배열 | 줄 추가·삭제·순서 | site_content (type: list) |
| 켜고 끄기 | 모집중, 배너 표시, 품절 | 스위치 | site_content (type: toggle) |
| 이미지 | `<img src>` 의 주소 | 주소 교체 칸 (업로드는 1판 범위 밖) | site_content (type: text) |

## 판단 표 (후보마다 채운다)
| 후보 | 남이 바꾸나 | 나 없이 바꾸나 | 자주 바꾸나 | 추천 |
|---|---|---|---|---|
| 문의 접수함 | 예 (손님이 씀) | 예 | 예 | 어드민 |
| 가격표 | 아니오 | 아니오 | 가끔 | 코드에 둔다 |
| 소개 문구 | 아니오 | 예 (폰으로) | 예 | 어드민 |

"남이"는 손님·팀원·가족 누구든 나 아닌 사람. "나 없이"는 노트북 없이·코드 몰라도. "자주"는 한 달에 한 번 이상.

## 제안 문안
"파악해 보니 문의 폼이 있고, 가격표와 소개 문구가 코드에 글자로 박혀 있습니다. 후보 넷입니다.
① 문의 접수함 — 손님이 쓰고, 나 없이, 자주 (셋 다 예) → 어드민
② 가격표 — 나 혼자, 가끔 → 코드에 두어도 됩니다
③ 소개 문구 — 폰으로 자주 고침 → 어드민
④ 외부 링크 목록 — 늘어남 → 어드민
어떤 걸 어드민으로 뺄까요? (여러 개 선택 가능 / 지금은 없음)"
AskUserQuestion 한 번. 첫 선택지는 추천 묶음, 마지막은 "지금은 없음".

## "지금은 없음"이거나 후보가 전부 아니오일 때
"지금은 어드민이 필요 없습니다. 바꿀 게 생기면 클로드에게 '소개 문구를 ○○로 바꿔 줘'라고 말하는 게 더 빠릅니다. 남이·나 없이·자주 중 하나라도 생기면 그때 다시 부르세요." 라고 말하고 끝낸다. 코드를 건드리지 않는다.

## 못 바꾸게 하는 것
레이아웃·색·페이지 구조·글꼴은 어드민에 넣지 않는다. 글자와 목록과 켜고 끄기만. "바뀌는 게 잦은 것만 어드민으로 뺀다."

## 설계도 v3
설계도 파일이 있으면 읽고 위 판단 표와 맞춘다(설계도가 더 많이 적었으면 이번엔 판단 표에 있는 것만 만들고 나머지는 "다음에"로 남긴다). 없으면 아래 10줄을 써서 보여 준다.
```
# 어드민 설계도 v3
바꿀 사람: (누구)
어드민 주소: /admin  ·  잠금: 비밀번호 하나
바꿀 항목:
- 소개 문구 (짧은 글) · 지금 값: "…"
- 외부 링크 (목록) · 지금 3개
- 문의 접수함 (접수함) · 상태: 새로 옴/확인/완료
안 바꾸는 것: 레이아웃·색·페이지 구조
확인 방법: 어드민에서 소개 문구 한 글자 바꾸고 사이트 새로고침
```
